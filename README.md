# Ежедневный отчёт по Яндекс.Метрике

Скрипт запускается по расписанию (cron на Render), забирает статистику
Cosmopolitan Atlas из Яндекс.Метрики, просит Claude написать короткий
разбор и публикует HTML-страницу в GitHub-репозиторий с включённым
GitHub Pages — получается стабильная ссылка, которую можно открыть
в любой момент.

## Что нужно подготовить

1. **Репозиторий для отчёта.** Новый небольшой репозиторий на GitHub
   (например `cosmopolitan-stats`), с включённым GitHub Pages:
   Settings → Pages → Deploy from a branch → `main` / `root`.
2. **Токен Яндекс.Метрики** (`metrika:read`) — см. инструкцию, которую
   прислала Claude в чате.
3. **Ключ Anthropic API** — console.anthropic.com → API Keys. Это
   отдельная оплата по токенам, не связана с подпиской claude.ai.
4. **GitHub Personal Access Token** с правом на запись в репозиторий
   (Settings → Developer settings → Fine-grained tokens → Contents: Read and write,
   ограничить только репозиторием отчёта).

## Переменные окружения для Render

| Переменная            | Значение                                              |
|------------------------|--------------------------------------------------------|
| `YANDEX_OAUTH_TOKEN`   | токен из шага 2                                        |
| `YANDEX_COUNTER_ID`    | `112345804` (уже стоит по умолчанию)                    |
| `ANTHROPIC_API_KEY`    | ключ из шага 3                                          |
| `GITHUB_TOKEN`         | токен из шага 4                                         |
| `GITHUB_REPO`          | `владелец/репозиторий`, например `nokio7077-art/cosmopolitan-stats` |
| `GITHUB_BRANCH`        | `main` (можно не задавать — это значение по умолчанию)  |

## Как разворачивается

Когда все переменные готовы — просто пришли их Claude (или введи
напрямую в Render после создания сервиса), и cron-задача будет
создана: Python-раннер, ежедневный запуск, `pip install -r requirements.txt`,
`python metrika_report.py`.

Первый запуск стоит сделать вручную (кнопка Trigger Run в Render) и
проверить логи — на случай если формат ответа Метрики слегка
отличается от ожидаемого, это единственное место, где может
понадобиться мелкая правка.
